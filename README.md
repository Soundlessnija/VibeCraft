# VibeCraft+

VibeCraft+ is a vanilla+ Minecraft modpack focused on exploration, atmosphere, farming, building, and relaxed progression.

This repository is primarily used for **bug reports, compatibility issues, and general issue tracking** for the modpack.

## Reporting an Issue

Before opening a new issue, please check the existing issues to make sure the problem has not already been reported.

When reporting a bug, include as much information as possible:

- A clear description of the problem
- What you were doing when the issue occurred
- Steps to reproduce the issue, if known
- Your VibeCraft+ version
- Minecraft version
- Relevant screenshots or videos
- `latest.log`
- Crash report, if one was generated

For performance problems, a Spark profile is also very helpful.

Please avoid posting only a screenshot of an error when a full log or crash report is available.

## Mod Compatibility

VibeCraft+ includes a large collection of mods, resource packs, shaders, compatibility patches, and configuration changes.

Some issues may be caused by interactions between multiple mods rather than a single project. If you have modified the pack by adding, removing, updating, or downgrading mods, please mention that in your report.

Issues from modified installations may be harder to reproduce.

## Suggestions

Feature suggestions and compatibility requests are welcome, but the goal of VibeCraft+ is to maintain a cohesive vanilla+ experience rather than add every available feature or mod.

## About VibeCraft+

VibeCraft+ expands Minecraft with richer terrain, changing seasons, improved wildlife, deeper farming and animal care, structures, atmospheric effects, and quality-of-life improvements while keeping the experience recognizable as Minecraft.

The pack is designed around slower-paced exploration, building, farming, and immersive gameplay without heavy tech or magic progression.
